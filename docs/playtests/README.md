# Play sessions

One file per session, named `YYYY-MM-DD.md`: who played, which build (commit), online or local, how many matches, and what people said.
Write down what was fun, what felt wrong, what broke, and what someone asked for.
New tickets cite the session file that motivated them.

Agent probes and native exploration may also be recorded here, explicitly labelled as such.
Separate measurements, observed UI behavior, design hypotheses and actual human feedback.
State content/build identity, how to repeat the trial, what passed, and which controls or evidence were unavailable.
Never call a scripted run or model review a human enjoyment test.
